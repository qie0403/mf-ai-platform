# 多功能AI工具平台
一站式AI生产力工具平台，基于Streamlit+大模型API开发，集成**智能对话、文档总结、文案生成、多模态图片解析**四大核心功能，是AI应用开发工程师的核心实战项目。

## ✨ 项目核心功能
1. **💬 智能对话**
   - 支持多轮对话，上下文记忆，页面刷新不丢失历史
   - 流式打字机输出，提升用户体验
   - 可自定义模型温度，调整输出严谨度/创造性
   - 一键清空对话历史

2. **📄 文档总结**
   - 支持PDF、DOCX、TXT三种格式文件上传
   - 内置4种总结模式：精简总结、详细总结、大纲式总结、核心要点提取
   - 支持自定义补充总结要求
   - 一键下载总结结果，原文预览功能

3. **✍️ 文案生成**
   - 内置6大高频文案场景：小红书文案、公众号推文、短视频脚本、商务邮件、工作总结、通用文案
   - 每个场景专属优化Prompt，保证输出符合平台调性
   - 支持自定义风格、字数要求，可生成多个差异化版本
   - 一键下载文案结果

4. **🖼️ 多模态图片解析**
   - 支持JPG、PNG、JPEG格式图片上传
   - 内置4种解析模式：图片整体描述、OCR文字提取、图片内容问答、细节深度分析
   - 基于多模态大模型，精准识别图片内容、文字、细节
   - 一键下载解析结果
